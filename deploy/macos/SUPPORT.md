# macOS delivery limits and acceptance

The launchd definition and signed installer builder package the existing native compatibility mode. They are not a complete macOS security product. Network Extension DNS filtering and Endpoint Security USB/application pre-execution enforcement are **not implemented**. Those components need a Mac build/test environment, Apple Developer ID, signing/notarization, and the entitlements approved by Apple. No entitlement placeholder or unsigned extension is presented as a working feature.

Build a native Mach-O `openems-agent` on a Mac, sign it using the organization's Developer ID Application identity and verify its signature. Set `OPENEMS_INSTALLER_IDENTITY` to the Developer ID Installer identity already available in the keychain; run `build-package.sh SIGNED-AGENT OUTPUT.pkg`. The script refuses a non-Mac host and an unsigned agent. Submit the final package through the organization's `notarytool` keychain profile and staple the accepted ticket before distribution. This repository does not store signing credentials or bypass Gatekeeper.

The installer creates private configuration/state directories and installs the daemon definition, but does not activate it before enrollment/configuration. Configure `/etc/openems/agent.json` using the native CLI and keep `dns_filter`, `anti_bypass`, and `block_page_https` disabled. Only explicit hosts-file domain blocking, policy synchronization/cache, and exact process-name termination are compatibility capabilities. Load using `launchctl bootstrap system /Library/LaunchDaemons/com.openems.agent.plist` only after reviewing the configuration. Root can stop this daemon; do not infer Windows tamper protection or tray notifications.

Mac acceptance remains external: signed/notarized install, enrollment, policy ACK, offline cache after reboot, launchd restart, explicit hosts blocking/release, process-name fallback and uninstall restoring the managed hosts block. Before removal, boot out the daemon, run `cleanup-hosts --config /etc/openems/agent.json`, and remove only the installed binary/plist; preserve private enrollment state until its lifecycle is agreed. Full DNS/USB/publisher/hash enforcement cannot be marked passed until the native extension implementations and physical Mac tests exist.
